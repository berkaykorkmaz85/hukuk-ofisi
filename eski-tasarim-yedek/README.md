# Eski Tasarım Yedeği

Bu klasör, tasarım sistemi dönüşümünden (nötr/minimalist palet) ÖNCEKİ
mor-lila temalı orijinal dosyaların birebir kopyasıdır.

Tasarım beğenilmezse geri dönmek için proje kökünden:

    cp eski-tasarim-yedek/index.html index.html
    cp eski-tasarim-yedek/01-cekirdek-veri.js js/01-cekirdek-veri.js
    cp eski-tasarim-yedek/02-dava-yonetimi.js js/02-dava-yonetimi.js
    cp eski-tasarim-yedek/03-icra-finans-gorev.js js/03-icra-finans-gorev.js
    cp eski-tasarim-yedek/04-arac-ve-modul.js js/04-arac-ve-modul.js
